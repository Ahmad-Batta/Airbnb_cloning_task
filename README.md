# Airbnb_cloning_task#

A responsive frontend clone of the Airbnb landing page built using **HTML5** and **Bootstrap 5**, focusing on a clean, modern design and utility-first styling.

## 🚀 Features

- **Navbar Layout**: Clean navigation featuring brand logo, category icons, and user authentication actions.
- **Interactive Search Bar**: A replica of Airbnb's iconic search component ("Where", "When", "Who") with structured grid layout and utility classes.
- **Property Listings**: Showcases popular properties and upcoming availability sections using Bootstrap cards.
- **Custom Badging**: Positioned badges for "Guest favourite" and wishlist heart icons.

## 🛠️ Built With

- **HTML5**
- **Bootstrap 5.3.3**
- **FontAwesome 6.4.0** (for icons)
